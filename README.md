# 🛒 NarigasCell - Loja de Celulares

Bem-vindo ao **NarigasCell**, uma loja de celulares online moderna e responsiva construída com HTML, CSS e JavaScript!

## ✨ Características

- 📱 **Catálogo Completo**: 8 celulares de marcas como Apple, Samsung, Motorola e Xiaomi
- 🛒 **Carrinho de Compras**: Adicione e remova produtos facilmente
- 🔍 **Filtros Avançados**: Filtre por marca e faixa de preço
- 💾 **Persistência**: Seu carrinho é salvo no localStorage
- 📱 **Responsivo**: Funciona perfeitamente em desktop, tablet e mobile
- 🎨 **Design Moderno**: Interface limpa e intuitiva

## 🚀 Como Usar

1. **Clonar o repositório**:
   ```bash
   git clone https://github.com/Hyrotex/narigascell.github.io.git
   cd narigascell.github.io
   ```

2. **Abrir no navegador**:
   - Abra `index.html` no seu navegador
   - Ou acesse: https://hyrotex.github.io/narigascell.github.io

## 💡 Funcionalidades

### 🔍 Filtro por Marca
Escolha entre as marcas disponíveis para ver apenas os produtos que te interessam.

### 💰 Filtro por Preço
Deslize o controle de preço para filtrar celulares dentro da sua faixa orçamentária.

### 🛒 Adicionar ao Carrinho
Clique em "Adicionar ao Carrinho" para adicionar produtos. Você pode adicionar o mesmo produto várias vezes.

### 📊 Ver Carrinho
Clique no ícone de carrinho no topo para ver todos os seus itens, quantidades e total.

### ✅ Finalizar Compra
Revise seus itens e clique em "Finalizar Compra" para completar a transação.
